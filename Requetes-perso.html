Requête Victor

L’objectif de ma requête est de repérer les produits qui se vendent le moins bien (25 pire) afin de leurs appliquer une remise qui pourrait les rendre plus attractif pour les entreprise.

Comment celle ci fonctionnerais ? Ma requête irais chercher les 25 Produits avec le moins de commande, les trierais pas leurs quantitée vendue (croissant) et sous trie par prix ( du plus cher au moins cher). Elle aƯicherais la ref du produit, le nom, le cout d’achat, la remise en %, la quantitée vendu du produit en question. 

SELECT TOP 25
        pds.RefProd,
        pds.NomProd,
        pds.CoutAchat,
        dcmd.[Remise (%)],
        SUM(dcmd.Quantité) AS QuantiteVendue
    FROM Produit AS pds
    INNER JOIN DetailCommande AS dcmd ON pds.RefProd = dcmd.[Réf produit]
    GROUP BY pds.RefProd, pds.NomProd, pds.CoutAchat, dcmd.[Remise (%)]
    ORDER BY SUM(dcmd.Quantité) ASC, pds.CoutAchat DESC

Quels sont les couples (client pilote, client partenaire) qui ont le même nombre de commandes ?

SELECT
    Pilote.CodeCli,
    Pilote.Societe,
    Partenaire.CodeCli AS CodePartenaire,
    Partenaire.Societe AS SocietePartenaire
FROM
    Clientele AS Pilote
INNER JOIN Clientele AS Partenaire ON Pilote.CodeCli = Partenaire.CodeCli
WHERE
    (
SELECT
COUNT(*)
FROM
    Commande
WHERE
    Commande.CodeCli = Pilote.CodeCli) =
        (
SELECT
COUNT(*)
FROM
        Commande
